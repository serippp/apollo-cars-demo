# Apollo Cars Detail — demonstração

Landing page estática em HTML, CSS e JavaScript, pronta para GitHub e Netlify.

## Estrutura

- `index.html` — conteúdo e estrutura da página
- `css/styles.css` — apresentação e comportamento responsivo
- `js/main.js` — menu, animações, packs e galeria
- `assets/images/` — logótipo e imagens utilizadas
- `netlify.toml` — configuração de publicação e cabeçalhos
- `robots.txt` — bloqueio de indexação enquanto o projeto for uma demonstração

## Publicar no Netlify

1. Carregar esta pasta para um repositório GitHub.
2. No Netlify, escolher **Add new site → Import an existing project**.
3. Ligar o repositório. O Netlify deteta `netlify.toml`; não é necessário comando de build.
4. Publicar.

Também é possível arrastar a pasta ou o ficheiro ZIP para o Netlify Drop.

## Antes do lançamento definitivo

- Confirmar textos, packs, número de telefone e área de atendimento com a Apollo Cars Detail.
- Confirmar autorização de utilização de todas as imagens do portefólio.
- Se o site deixar de ser uma demonstração, remover `noindex, nofollow, noarchive` do `index.html` e substituir o conteúdo de `robots.txt` por regras de indexação adequadas.
- Configurar o domínio e rever os textos legais aplicáveis.

Não existem dependências, formulários externos, serviços internos ou passos de compilação.

As imagens utilizadas foram obtidas do portefólio público do perfil oficial `@apollocars__` em 24/09/2026. Confirme com o cliente a autorização para utilização definitiva antes do lançamento público.
